# F.O.O.G.

Official website of the **Φυσιολατρικός Ορειβατικός Όμιλος Γιαννιτσών (F.O.O.G.)**.

Built with Astro and Tailwind CSS. The site is deployed via GitHub Pages at **https://www.foog.gr**.

## Development

### Requirements

- Node.js 20+

### Install

```bash
npm install
```

### Run locally

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```

## Tech Stack

- Astro
- TypeScript
- Tailwind CSS
